Enter pool volume in litres, measured or manufacturer-rated flow in litres per minute, and the target turnovers per day. Turnover hours = litres ÷ (litres per minute × 60); daily run time is turnover hours multiplied by the chosen turnovers.

Actual flow changes with pump speed, plumbing resistance and filter condition, so use a flow meter or the pump curve where possible. This is a hydraulic estimate, not a universal operating recommendation. Start with the Australian pool volume calculator if volume is unknown.
