Route optimisation is a better starting order

Most wasted driving is not dramatic. It is the quiet accumulation of crossing the same arterial twice, doubling back to a neighbouring suburb or leaving the furthest stop until late afternoon. For a sole trader, those kilometres consume fuel, vehicle time and the gap that could have held one more service.

PoolFlow uses the selected pool addresses to build a route from nearby stops and then improve it with additional route comparisons. That gives the day a considered starting point. It does not claim perfect optimisation, predict every delay or remove the need to review the run.

Plan, check, drive, learn

1. Select today’s pools

Build the run from the services actually due. Clean address data gives the route engine a better foundation.

2. Optimise the order

Generate a stop sequence that reduces avoidable geographic backtracking across the chosen pools.

3. Apply constraints

Move fixed appointments, school-zone stops, gated properties and chemical collection into practical positions.

4. Use the run sheet

Work through the route with each pool’s records ready for service logging, chemistry and notes.

What PoolFlow includes

  • Daily selection of the pools to visit
  • Automatic stop ordering based on location
  • A nearest-neighbour starting route with improvement passes
  • Map-based ETA support when the service is available
  • A fallback distance approach when live ETA is unavailable
  • Integration with the pool record and service workflow

What it does not promise

  • A guaranteed globally shortest route
  • Perfect knowledge of live incidents, roadworks or weather
  • Automatic understanding of every appointment or gate constraint
  • Multi-vehicle territory planning or dispatcher controls
  • Live tracking for customers or office staff
  • Safe navigation in place of the driver’s judgement and road rules

Make the route data worth using

Standardise addresses, keep gate notes current and separate fixed-time appointments from flexible maintenance stops. If the first stop changes because the ute needs chemicals, recheck the remaining order rather than following yesterday’s habit.

Distance is only one part of route profitability. Pair route planning with per-pool chemical cost tracking. A compact route can still underperform when a few pools consume disproportionate chemicals or unrecorded time.
